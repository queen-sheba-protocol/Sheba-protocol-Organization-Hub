# Weekly Sync Checklist

Use this checklist for your track's weekly synchronization meeting.

## Before the Meeting (15 mins)

### Individual Preparation
- [ ] Review your assigned issues
- [ ] Update issue status to reflect current work
- [ ] Prepare list of blockers (if any)
- [ ] Document progress since last sync
- [ ] Identify help needed from team

### Track Lead Preparation
- [ ] Review all team member progress
- [ ] Check milestone status vs. due dates
- [ ] Identify at-risk items
- [ ] Prepare agenda

## During the Meeting (30-45 mins)

### Opening (5 mins)
- [ ] Review agenda
- [ ] Remind team of quarterly goals

### Individual Updates (20-30 mins)
For each team member:
- [ ] **What did you work on this week?**
  - Reference GitHub issues
  - Share key learnings
  - Show progress (% complete)
  
- [ ] **What are you working on next week?**
  - Next priority tasks
  - Estimated completion dates
  
- [ ] **What's blocking you?**
  - Technical blockers
  - Resource needs
  - External dependencies

### Milestone Review (5-10 mins)
- [ ] Current milestone on track?
- [ ] Any scope changes?
- [ ] Do we need to adjust timeline?

### Action Items (5 mins)
- [ ] Document decisions
- [ ] Assign owners for blockers
- [ ] Update issues with action items
- [ ] Schedule deep dives or reviews

## After the Meeting (15 mins)

### Track Lead Actions
- [ ] Update track roadmap with progress
- [ ] Close completed issues
- [ ] Update milestone dates if needed
- [ ] Communicate status to organization

### All Team Members
- [ ] Update Daily Progress Tracker
- [ ] Commit progress notes
- [ ] Update assigned issues
- [ ] Mark action items as in-progress

## Sample Agenda Template

```
[Track Name] Weekly Sync
When: [Day] [Time]
Duration: 45 minutes
Attendees: [Team lead], [Team members]

1. Opening & Agenda (5 min)
2. Team Updates (25 min)
   - [Member 1]: Status update
   - [Member 2]: Status update
   - [Member 3]: Status update
3. Milestone Review (10 min)
4. Blockers & Action Items (5 min)
5. Next Week Planning (5 min)

Action Items:
- [ ] [Owner]: [Task] [Due]
```

## Tips for Effective Syncs

✅ **DO:**
- Keep updates focused and time-boxed (2-3 mins per person)
- Reference GitHub issues with numbers (#1, #2)
- Be specific about blockers
- Celebrate wins and completed milestones
- Share learning moments
- Record decisions and action items

❌ **DON'T:**
- Get into deep technical dives (save for separate meetings)
- Discuss unrelated topics
- Skip the sync if things aren't going well (exactly when you need it!)
- Leave action items without owners
- Forget to update issues after the meeting

## Example Status Update

**Good example:**
```
Worked on: OWASP API Top 10 research (#5)
- Completed study of API authentication vulnerabilities
- Found 3 key bypass techniques worth documenting
- 60% complete on research, 30% on writeup

Next week: Continue writeup & start lab exploitation

Blocker: Need access to OWASP API security lab environment
Ask: [Track lead] - can you grant lab access?
```

**Not specific enough:**
```
Worked on stuff for my track
Need help with something
```
